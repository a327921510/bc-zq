# 上线与发版手册（零基础版）

本文面向**不熟悉开发**的同事：按顺序点宝塔面板、复制命令即可完成「首日上线」和「以后每次发版」。

> **约定目录（全文统一用这个路径）**  
> 项目放在服务器：`/www/wwwroot/bc-zq`  
> 若你改了目录名，文中所有路径都要一起改。

---

## 开始前请准备

| 准备项 | 说明 |
|--------|------|
| 一台阿里云 ECS | 建议 2 核 2G 起，已装好 **宝塔面板** |
| 能登录宝塔 | 浏览器打开面板地址，能进「文件 / 网站 / 软件商店」 |
| 本机项目包 | 开发同事给你的 zip，**或** 仓库地址（会用 git 的人） |
| 你的公网 IP | 手机/电脑浏览器打开 https://ip.sb ，记下数字，如 `1.2.3.4` |
| （可选）域名 | 已解析到 ECS 公网 IP；没有域名可用 `http://服务器IP/zq/` |

### 绝对不要做的事

- 不要把本机电脑上的 `data/`、`backups/`、`.venv/` 文件夹覆盖到服务器（会丢数据或路径错乱）。
- 不要在阿里云安全组里对**公网**开放端口 `8000`。
- 发版时不要「整站覆盖上传」把服务器上已有的 `data/`、`backups/` 冲掉。

## 一、首日上线（只做一次）

按 **步骤 1 → 10** 做完即可。每步做完打个勾。

### 步骤 1：安全组（阿里云控制台）

1. 打开阿里云 → 云服务器 ECS → 你的实例 → **安全组** → 配置规则。
2. 入方向放行：
   - `80`（HTTP）
   - `443`（HTTPS，有域名再申请证书时用）
   - `8888` 或你的宝塔面板端口（仅建议自己用）
3. **不要**添加「对所有人开放 8000」的规则。

### 步骤 2：时区改成上海（很重要）

收盘后自动同步依赖北京时间。在宝塔：

1. 左侧 **终端**（或 SSH 登录服务器）。
2. 复制粘贴下面两行，回车：

```bash
timedatectl set-timezone Asia/Shanghai
timedatectl
```

3. 输出里应看到 `Asia/Shanghai` 或 `CST`。

### 步骤 3：宝塔安装必要软件

左侧 **软件商店**，安装（没有就点安装）：

1. **Nginx**（网站用）
2. **Supervisor 管理器**（让后台程序开机自启；有的面板叫「进程守护管理器」）
3. **Python 项目管理器** 或确认系统已有 Python 3.10+  
   终端执行：`python3 --version`，能显示版本即可。
4. **Node.js 版本管理器**（或 Node 18/20）：用来构建网页前端。  
   装完后终端执行：`node -v`、`npm -v`，都有版本号即可。

不必强行装 MySQL，本项目用自带的 SQLite 文件库。

### 步骤 4：把项目放到服务器

下面两种方式 **选一种**。

#### 方式 A：上传 zip（更适合不懂 git 的人）

1. 让开发同事给你 **不含** 下列文件夹的压缩包（或你解压后自己删掉再传）：
   - `.venv/`
   - `node_modules/`
   - `data/`（首日可以没有）
   - `backups/`
   - `frontend/dist/`（服务器上会重新构建）
2. 宝塔 → **文件** → 进入 `/www/wwwroot/`。
3. 新建文件夹：`bc-zq`。
4. 进入 `bc-zq`，点 **上传**，上传 zip，再 **解压**。
5. 解压后目录里应能看到：`backend/`、`frontend/`、`ops/`、`README.md`、`requirements.txt` 等。

#### 方式 B：git clone（有仓库地址时）

在宝塔 **终端** 执行（把地址换成真实仓库）：

```bash
cd /www/wwwroot
git clone 这里换成仓库地址 bc-zq
cd bc-zq
ls
```

能看到 `backend`、`frontend`、`ops` 等即可。

### 步骤 5：一键初始化环境

> **先确认 Python 版本（本步最容易踩坑）**  
> 终端执行：`python3 --version`  
> 必须是 **3.10 或更高**（如 `Python 3.10.12`）。若是 `3.6` / `3.7` / 更低，或后面装依赖时报 `No matching distribution found for fastapi==…`、并提示 `pip version 9.x`：说明系统 Python 太旧。请到宝塔 **软件商店 → Python 项目管理器** 安装 **Python 3.10+**，再用该解释器建虚拟环境（见下方「Python 太旧时」）。

在宝塔 **终端** 依次执行（整段复制）：

```bash
cd /www/wwwroot/bc-zq

# 若提示没有 make，用后面的「无 make 版」
make bootstrap
```

**如果提示 `make: command not found`**，改用下面整段：

```bash
cd /www/wwwroot/bc-zq
python3 --version   # 确认 ≥ 3.10
rm -rf .venv        # 若上次失败建过半截 .venv，先删掉再建
python3 -m venv .venv
.venv/bin/pip install -U pip setuptools wheel -i https://mirrors.aliyun.com/pypi/simple/
.venv/bin/pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
cp -n .env.example .env
cp -n ops/allowed_ips.conf.example ops/allowed_ips.conf
mkdir -p logs backups/db data
.venv/bin/python -m backend.src.db init
```

**Python 太旧时**（版本低于 3.10）：在宝塔装好 Python 3.10+ 后，把上面的 `python3` 换成实际路径，例如：

```bash
# 路径以你面板里显示的为准，常见类似：
# /www/server/pyporject_evn/versions/3.10.12/bin/python3
PY=/www/server/pyporject_evn/versions/3.10.12/bin/python3
cd /www/wwwroot/bc-zq
rm -rf .venv
"$PY" -m venv .venv
.venv/bin/pip install -U pip setuptools wheel -i https://mirrors.aliyun.com/pypi/simple/
.venv/bin/pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
cp -n .env.example .env
cp -n ops/allowed_ips.conf.example ops/allowed_ips.conf
mkdir -p logs backups/db data
.venv/bin/python -m backend.src.db init
```

成功标志：最后没有红色报错；目录里出现 `.venv/`、`.env`、`ops/allowed_ips.conf`、`data/`。

### 步骤 6：改配置文件 `.env`

1. 宝塔 → **文件** → `/www/wwwroot/bc-zq/.env` → 编辑。
2. **整份改成下面内容**（路径不要改错；若目录名不是 `bc-zq` 请替换）：

```ini
DATA_DIR=/www/wwwroot/bc-zq/data
BACKUP_DIR=/www/wwwroot/bc-zq/backups
DB_PATH=/www/wwwroot/bc-zq/data/archive.db
API_HOST=127.0.0.1
API_PORT=8000
BASE_PATH=/zq
HTTP_TIMEOUT=30

IP_WHITELIST_ENABLED=false
IP_WHITELIST_PATH=/www/wwwroot/bc-zq/ops/allowed_ips.conf

SYNC_COOLDOWN_SECONDS=120
SYNC_OK_REUSE_SECONDS=600
SYNC_BATCH_GAP_SECONDS=2
SYNC_REQUEST_GAP_SECONDS=0.4
```

3. 保存。

### 步骤 7：填写 IP 白名单（否则网页会 403）

1. 浏览器打开 https://ip.sb ，复制你的公网 IP。
2. 宝塔 → **文件** → `/www/wwwroot/bc-zq/ops/allowed_ips.conf` → 编辑。
3. 改成类似下面（把 `1.2.3.4` 换成你的 IP；**最后一行 `deny all;` 必须保留**）：

```nginx
# 允许访问的公网 IP（可多行）
allow 1.2.3.4;

deny all;
```

4. 保存。  
   以后换网络（家/公司/手机热点）IP 变了，就在这里再加一行 `allow 新IP;`，然后 **重载 Nginx**（见步骤 9）。

### 步骤 8：构建网页 + 启动后台 API

#### 8.1 构建前端页面

终端执行：

```bash
cd /www/wwwroot/bc-zq/frontend
npm ci
npm run build
```

成功标志：出现 `frontend/dist/` 文件夹，里面有 `index.html`。

#### 8.2 用 Supervisor 常驻启动 API

1. 宝塔 → **软件商店** → 已安装 → 找到 **Supervisor** / 进程守护 → **设置**。
2. 添加守护进程，建议填写：

| 项 | 填写内容 |
|----|----------|
| 名称 | `byd-api`（以后发版重启会用到这个名字） |
| 启动用户 | `root` 或与网站相同的用户（以面板默认可跑通为准） |
| 运行目录 | `/www/wwwroot/bc-zq` |
| 启动命令 | 见下方，**一行复制** |

启动命令（必须整行一致）：

```text
/www/wwwroot/bc-zq/.venv/bin/uvicorn backend.src.api:app --host 127.0.0.1 --port 8000 --workers 1
```

3. 保存并 **启动**，状态应为「运行中」。
4. 在终端自检：

```bash
curl -s http://127.0.0.1:8000/zq/api/health
```

应返回类似：`{"status":"ok"}`（具体字段以实际为准，关键是有 JSON、不是连不上）。

> 若 Supervisor 插件不好用：可用宝塔「Python 项目」托管，启动命令与上面相同，工作目录同为 `/www/wwwroot/bc-zq`，workers 必须为 **1**。

### 步骤 9：添加网站并配置 Nginx

1. 宝塔 → **网站** → **添加站点**。
   - 域名：填你的域名；没有就填服务器公网 IP。
   - 根目录：可先保持默认（本应用页面由后端托管，主要靠反代）。
2. 点站点右侧 **设置** → **配置文件**。
3. 在 `server { ... }` **里面**（注意：不要贴到外面），粘贴下面整段（目录若不同请改路径）：

```nginx
# —— IP 白名单 ——
include /www/wwwroot/bc-zq/ops/allowed_ips.conf;

# —— 防收录 ——
location = /robots.txt {
    root /www/wwwroot/bc-zq/ops;
    default_type text/plain;
}

location = /zq {
    return 301 /zq/;
}

location /zq/ {
    proxy_pass http://127.0.0.1:8000/zq/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_read_timeout 300s;
}
```

4. 点 **保存**。
5. 软件商店 → Nginx → **重载配置**（或站点页「重载」）。
6. （推荐）站点 → **SSL** → 申请 Let's Encrypt → 开启「强制 HTTPS」。

仓库里同内容文件：`ops/nginx-site.snippet.conf`，可对照。

### 步骤 10：设置每天自动同步（收盘后）

1. 宝塔 → **计划任务** → 添加任务。
2. 建议填写：

| 项 | 填写 |
|----|------|
| 任务类型 | Shell 脚本 |
| 任务名称 | `bc-zq-sync` |
| 执行周期 | 每天，**16:00** |
| 脚本内容 | 见下（一行） |

```bash
/www/wwwroot/bc-zq/backend/scripts/sync_today.sh
```

3. 打开「保存任务日志」，方便出问题查看。
4. （可选）当天是交易日时，可点「执行」试跑一次；非交易日脚本可能直接跳过，属正常。

## 二、首日验收（全部勾上才算上线成功）

在你自己的网络下（IP 已写入白名单）检查：

- [ ] 浏览器打开：`https://你的域名/zq/` 或 `http://服务器IP/zq/`，能看到回放/管理页面
- [ ] 打开：`https://你的域名/zq/api/health`，有正常 JSON 响应
- [ ] 换一个**未**加入白名单的网络（如手机关 Wi‑Fi 用流量）访问，应为 **403** 无法打开
- [ ] 宝塔 Supervisor 里 `byd-api` 为运行中
- [ ] 计划任务列表能看到每天 16:00 的 `bc-zq-sync`
- [ ] 终端执行：

```bash
cd /www/wwwroot/bc-zq
.venv/bin/python -m backend.src.db version
```

能打印出版本数字（≥ 1）

交易日可再手动拉一只样例数据：

```bash
cd /www/wwwroot/bc-zq
.venv/bin/python -m backend.src.sync --code 002594 --backup
```

然后在网页里看是否有当日数据。

## 三、以后每次发版（有新版本时）

日常发版**不要**再整包覆盖上传。按下面做。

### 3.1 代码怎么更新

**若服务器是 git 仓库：**

在终端执行：

```bash
cd /www/wwwroot/bc-zq
DEPLOY_GIT_PULL=1 DEPLOY_RESTART_CMD='supervisorctl restart byd-api' ./backend/scripts/deploy.sh
```

说明：

- 会自动：备份数据库 → 升级表结构 → 安装 Python 依赖 → 构建前端 → 重启 `byd-api`
- 若 `supervisorctl` 报错，到宝塔 Supervisor 面板里手动点 **重启** `byd-api` 即可

**若平时用 zip 更新：**

1. 只上传/覆盖 **代码相关** 目录（如 `backend/`、`frontend/src/`、`frontend/package.json`、`requirements.txt`、脚本等）。
2. **千万不要覆盖** 服务器上的：`data/`、`backups/`、`.env`、`ops/allowed_ips.conf`、`.venv/`。
3. 然后执行：

```bash
cd /www/wwwroot/bc-zq
./backend/scripts/deploy.sh
```

4. 宝塔 Supervisor → 重启 `byd-api`。
5. 浏览器强制刷新页面（Ctrl/Cmd + Shift + R）再验收。

### 3.2 发版后快速自检

```bash
curl -s http://127.0.0.1:8000/zq/api/health
cd /www/wwwroot/bc-zq && .venv/bin/python -m backend.src.db version
```

再打开网页确认功能正常。

### 3.3 只改了白名单 IP、没发版代码时

1. 编辑 `ops/allowed_ips.conf`，增加 `allow 新IP;`
2. 保存 → Nginx **重载**
3. **不必**重启 `byd-api`

## 四、常见问题

| 现象 | 可能原因 | 怎么处理 |
|------|----------|----------|
| 网页 403 | IP 不在白名单 | 查 https://ip.sb，写入 `allowed_ips.conf`，重载 Nginx |
| 网页 502 / 打不开 | API 没在跑 | Supervisor 看 `byd-api` 是否运行；看启动日志 |
| `curl health` 失败 | 端口/进程问题 | 确认启动命令里是 `127.0.0.1:8000`，workers=1 |
| 页面空白或样式丢失 | 没构建前端 | 重新执行 `cd frontend && npm ci && npm run build`，再重启 API |
| 计划任务没数据 | 非交易日，或脚本失败 | 看 `logs/sync.log`；交易日手动跑一次 `sync_today.sh` |
| 发版后数据没了 | 误覆盖了 `data/` | 立即停 API，从 `backups/db/` 里最新的 `archive_pre_deploy_*.db` 拷回 `data/archive.db`，再启动 |

回滚数据库示例（先停 `byd-api`）：

```bash
cd /www/wwwroot/bc-zq
ls -lt backups/db/ | head
# 把下面文件名换成你看到的最新备份
cp -a backups/db/archive_pre_deploy_某时间.db data/archive.db
```

然后 Supervisor 再启动 `byd-api`。

## 五、给会一点命令的人：命令速查

| 目的 | 命令 |
|------|------|
| 首日初始化 | `cd /www/wwwroot/bc-zq && make bootstrap` |
